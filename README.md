# 🧭 AI / ML / Data Science Roadmap & Study Guide

An aesthetic, interactive single-file study dashboard that breaks down the complete Artificial Intelligence, Machine Learning, and Data Science learning journey into 6 practical stages. Built with vanilla web technologies, persistent checklist progress, inline visual explanations, and quick-reference cheat sheets.

---

## ✨ Features

- **🗺️ 6-Stage Curated Pathway**:
  1. **Tools & Workshop:** Python, NumPy, Pandas, Matplotlib/Seaborn, Git/GitHub, Jupyter/Colab, SQL.
  2. **Essential Math Intuition:** Linear Algebra, Calculus (Gradients), Probability & Bayes, Statistics.
  3. **Core Machine Learning:** Supervised/Unsupervised models, Overfitting, Train/Test split, scikit-learn, and the ML feedback loop.
  4. **Deep Learning:** Neural networks, Backpropagation, PyTorch/TensorFlow, CNNs, RNNs/LSTMs, and Transformers.
  5. **Specialization Tracks:** Computer Vision, NLP & LLMs (RAG, fine-tuning), Time Series, Recommenders, and Reinforcement Learning.
  6. **Shipping to Production:** Portfolio building, Streamlit, FastAPI, Docker, and Kaggle competitions.
- **💾 Auto-Saving Progress Bar**: Interactive checkboxes for every milestone that automatically save your completed topics to your browser (`localStorage`).
- **📊 Embedded Visuals & Interactive Diagrams**:
  - Gradient descent convergence illustration.
  - Neural network input-hidden-output architecture schematic.
  - Overfitting vs. model complexity curve.
  - Confusion matrix reference table (TP, FP, FN, TN).
  - Real-world project effort breakdown chart (Data cleaning ~60% vs. modeling ~10%).
- **⚡ End-to-End Cheat Sheet**:
  - Algorithm selector guide ("Which algorithm to pick first?").
  - Plain-English evaluation metric breakdowns (Accuracy, Precision, Recall, F1, RMSE, R²).
  - Model diagnostic & debugging tips (Underfitting vs. Overfitting vs. Data Leaks).
  - 5 Golden rules for real-world projects.
- **📚 Curated Resources**: Quick reference links to Andrew Ng's Coursera courses, fast.ai, 3Blue1Brown, Kaggle Learn, and Aurélien Géron's hands-on guide.
- **🌗 Responsive & Theme-Aware**: Supports native automatic dark and light modes with custom modern typography (`Bricolage Grotesque` & `Nunito Sans`).

---

## 🛠️ Built With

- **HTML5**
- **Modern CSS3** (CSS custom variables, Flexbox/Grid layouts, dynamic light/dark mode queries)
- **Vanilla JavaScript** (Zero dependencies, DOM manipulation, client-side persistence via `localStorage`)
